# Monitor TUI 文件与十六进制编辑器

文件面板使用当前挂载的 FAT32 卷。Tab 切换焦点，方向键选择目录项；列表每页显示 18 项，选择越过当前页会自动滚动。

- F2 / Enter：进入选中的目录；`.` 留在当前目录，`..` 返回上级。
- F5：重新读取目录。
- F6：将选中的普通文件载入十六进制编辑器。

编辑器自动读取文件，显示十六进制及 ASCII；打开失败会留在文件面板显示错误码。

- 方向键 / PageUp / PageDown：移动；Home 到文件起点，End 到 EOF（满容量时到最后一个字节）。
- 输入两个十六进制数字，再按 Enter 提交一个字节；移动会取消未提交字节，Esc 也可取消。
- 在 EOF 后提交字节可扩展文件，中间空隙填零；不支持插入、删除或截断。
- F1：重新载入；有修改时用 Y 确认放弃，N / Esc 取消。
- F2：保存；存在未提交字节时须先提交或取消。只读文件禁止修改和保存。
- Esc / F3：返回面板；有未保存修改时确认是否放弃。

目前文件容量上限为 **64 KiB**，目录最多展示前 **256 个有效条目**，达到上限时显示提示。编辑和重载分别使用 monitor BSS 中的有界缓冲；链接器检查映像及栈不会覆盖 `0x350000` 起的固定区域，不再使用 `0x400000` 固定编辑缓冲或尚未统一的分配器。

重载失败保留原编辑内容。保存错误显示错误码及已写字节数，并阻止继续使用该会话重试保存，须重新载入或退出。底层 FS 不提供事务回滚，部分写入或同步失败可能已经改变磁盘。

## 验证

```sh
make
make test-tui-hex
make test-fs
python3 tests/tui_hex_test.py
```

宿主测试直接调用实际 TUI 事件处理器及 FAT 实现，覆盖边界、空文件/目录、只读、错误恢复、保存和目录导航。QEMU 测试使用临时镜像副本，验证实际按键、保存后重新启动及放弃修改；PC 使用 IDE，Q35 添加兼容 IDE 控制器（不代表已支持 AHCI 驱动）。
